## 🚀 Featured Projects

### 🚗 [FleetPulse — Automotive Telemetry Intelligence Platform](https://github.com/VViswaPrahlad/FleetPulse)

A full-stack automotive telemetry analytics and ML platform built on real vehicle data.

**Tech Stack:** Python · PySpark · DuckDB · FastAPI · React · TypeScript · scikit-learn

- Processed **22.4 million+ telemetry observations** across 384 vehicles.
- Built reproducible Bronze, Silver, and Gold data pipelines.
- Developed interactive fleet analytics, driving behavior, and data quality dashboards.
- Trained a next-minute speed forecasting model with **22.55% lower pooled test MAE** than the last-observed-speed baseline.
- Built versioned REST APIs and validated local model inference.

### 📄 [DocQuery — Multi-Document RAG Application](https://github.com/VViswaPrahlad/DocQuery)

An AI-powered document question-answering application with transparent retrieval and page-level citations.

**Tech Stack:** Python · Streamlit · FAISS · BM25 · BGE Embeddings · Groq API

- Ask questions across multiple PDF documents.
- Inspect retrieved evidence and document/page references.
- Compare dense, lexical, and hybrid retrieval methods.
- Support document summarization and conversational follow-ups.

**🌐 [Try DocQuery Live](https://docquery-rag.streamlit.app)**
